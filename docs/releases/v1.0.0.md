The first release of Affice: a free, open-source office suite for Windows and Linux with **Documents**, **Sheets** and **Slides**.

## Which file do I need?

| Your computer | Download |
| --- | --- |
| Windows 10 or 11 (most PCs) | `Affice-Setup-1.0.0-x64.exe` |
| Windows on an older 32-bit PC | `Affice-Setup-1.0.0-ia32.exe` |
| Windows on ARM (Surface Pro X, Snapdragon laptops) | `Affice-Setup-1.0.0-arm64.exe` |
| Windows, without installing (runs from a folder or USB stick) | `Affice-Portable-1.0.0-x64.exe` |
| Ubuntu, Debian, Linux Mint, Pop!_OS | the `amd64.deb` (or `arm64.deb` on ARM) |
| Fedora, openSUSE, RHEL | the `.rpm` |
| Any other Linux | the `.AppImage` (make it executable and run it) or the `.tar.gz` |

<!-- signing --> `SHA256SUMS.txt` lists the checksum of every file.

## What's in 1.0

- **One app, three editors**: a dashboard with 16 templates, tabs for everything you open, and a command palette (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd>)
- **Documents**: print layout with real pages, styles, tables, pictures, headers and footers, comments, a table of contents, equations and slash commands
- **Sheets**: about 490 Excel-compatible functions (including `XLOOKUP`, `FILTER` and `LAMBDA`), conditional formatting, charts, tables, sorting and filtering, and goal seek
- **Slides**: 12 designs, shapes, icons, tables and charts, transitions including Morph, animations, and a slide show with presenter view, pen and laser pointer
- **Your files, your way**: opens and saves Word, Excel, PowerPoint and OpenDocument files (`.docx`, `.xlsx`, `.pptx`, `.odt`, `.ods`, `.odp` and more) by itself, and exports to PDF, HTML, EPUB, Markdown, CSV and JSON
- **Kind to older computers**: a performance mode, reduced or no animation, a compact layout and 32-bit and ARM builds
- **Free for good**: MIT licensed, with no account, no subscription and no telemetry
